# yazici-tarayici-test-sayfalari
Yazıcı ve tarayıcıların baskı, renk, ton, metin, OCR, çözünürlük, hizalama ve geometri özelliklerini kontrol etmek için hazırlanmış A4 test sayfaları. PDF dosyaları yüzde 100 ölçekte yazdırılacak şekilde düzenlenmiştir. Tarayıcı testleri 300 ve 600 DPI karşılaştırmalarında kullanılabilir.
